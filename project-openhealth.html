OpenHealth

Private, local-first Apple Health export for iPhone and iPad — you choose what to read and where the files go.

View on GitHub All Projects

Overview

OpenHealth is an iOS and iPadOS 17+ app for exporting your own Apple Health data. It reads from HealthKit only after an explicit user action, never writes to it, and does not collect any data itself. The project is in active development: the core logic is covered by tests, while full Xcode and on-device verification is still underway.

Highlights

  • Read-only HealthKit access covering quantity and category metrics, plus workouts, workout routes, ECG and activity summaries.
  • Exports to CSV, versioned JSON (schema v1) and GPX for workout routes.
  • Delivers files to Local Files, iCloud Drive or a REST API over HTTPS.
  • Credentials are stored as Keychain references only, and workout routes — which contain precise location — are off by default.
  • Scheduled exports (hourly, daily, weekly or monthly) run on a best-effort basis through background app refresh.
  • Foundation-only core domain with no third-party runtime dependencies, backed by a 91-test suite.
