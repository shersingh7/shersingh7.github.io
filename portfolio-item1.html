Chat App

A one-to-one Android chat app in Kotlin, with Firebase Authentication and messages synced live through Firebase Realtime Database.

View on GitHub All Projects

Overview

Chat App lets people create an account, see everyone else who has signed up, and open a private conversation with any of them. Firebase handles both sign-in and storage, so messages appear on both devices as soon as they are sent, without a custom backend.

Context: an early Android project, last updated in 2021, built to learn Kotlin and Firebase fundamentals.

Highlights

  • Email and password sign-up, log-in and sign-out with Firebase Authentication; each user’s profile is stored under user/<uid>.
  • A home screen listing registered users in a RecyclerView; tapping a name opens the chat.
  • Every message is written to both a sender room and a receiver room under chats/<room>/messages, so each side of the conversation updates in real time.
  • A simple structure of four activities — LogIn, SignUp, MainActivity and ChatActivity — with separate adapters for users and messages.
  • Material Components and ConstraintLayout for the UI, supporting Android 8.1 (API 27) and up.
