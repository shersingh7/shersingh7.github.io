Open TTS

Fully local, multi-model text-to-speech for Apple Silicon, with a Chrome extension that reads any selected text aloud.

View on GitHub All Projects

Overview

Open TTS runs text-to-speech entirely on your Mac, with no cloud calls. A local Python server runs MLX-optimized inference for three models — Kokoro, Qwen3-TTS and Fish Audio S2 Pro — and a Chrome MV3 extension lets you select text on any page and hear it. It requires an Apple Silicon Mac (M1 or later) on macOS 14+.

Highlights

  • Switch between Kokoro (82M parameters, the lightweight default), Qwen3-TTS and Fish Audio S2 Pro; only one model is held in memory at a time and swaps on demand.
  • All processing happens locally — text never leaves the machine.
  • 19 preset voices for Kokoro, 9 for Qwen3-TTS, and SSML voice tags for Fish; Qwen3 adds English, Chinese, Japanese and Korean with auto-detect.
  • Chrome extension with a right-click “Read with Open TTS” action (works in PDFs), Alt+Shift+R / Alt+Shift+P shortcuts, and per-site widget hiding.
  • Start and stop the server straight from the extension popup via a native messaging host — no terminal needed day to day.
  • Long selections play progressively in a dedicated Reader tab; failed passages stop with a visible error instead of silently skipping or replaying content.
