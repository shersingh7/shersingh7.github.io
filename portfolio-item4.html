Desi Khanna

An Indian food-ordering site built with Node.js, Express and MongoDB, with accounts, a clerk role for managing meals, and a session-based cart.

View on GitHub All Projects

Overview

Desi Khanna is a server-rendered Express app organised in an MVC style — controllers, Mongoose models, and Handlebars views and partials. Customers browse meal packages, build a cart and place orders; data-entry clerks maintain the menu. Built for Seneca’s WEB322 course in Winter 2021 as a full pass through auth, persistence and transactional email.

Highlights

  • Registration with bcrypt-hashed passwords and a SendGrid welcome email; login state held in express-session.
  • Two roles — customer and data-entry clerk — with separate views after sign-in.
  • Clerks add and edit meal packages, including photo uploads via express-fileupload.
  • Customers browse “On the Menu” and top meals, open meal descriptions, and add items to a session-based cart with a running total.
  • Placing an order sends the customer an order summary by email; data lives in MongoDB through Mongoose, with mongodb-memory-server for local development.
