Google Lens Clone

An Android visual-search app that labels objects, reads text and scans barcodes on-device with ML Kit, then searches the web for what it finds.

View on GitHub All Projects

Overview

Google Lens Clone takes a photo from the camera, the gallery or another app’s share sheet and analyses it on the device with Google ML Kit. Depending on the mode, it identifies what is in the picture, extracts the text or decodes a barcode, and it can run a web search on the detected labels.

Context: first built in 2021 around Firebase ML Kit object detection, then rebuilt as v2.0 in 2026 with a Material 3 interface and a wider set of analysis modes.

Highlights

  • Three analysis modes: image labeling with confidence scores, text recognition with copy and share, and barcode/QR scanning with type detection and an open-link action for URLs.
  • On-device ML Kit APIs for image labeling, text recognition, barcode scanning and object detection.
  • Web search for detected labels through SerpAPI, with results shown as cards (Volley and OkHttp for requests, Glide for images).
  • Images come from the camera, the gallery, or straight from other apps via the share sheet.
  • Search history persisted locally with Room, in a dark-first Material 3 design targeting API 34 (minimum API 26).
